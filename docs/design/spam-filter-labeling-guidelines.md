# 广告邮件过滤标注准则草案

> 版本：v0.1
>
> 日期：2026-07-20
>
> 适用范围：S0 测试基线与 P2-P4 离线回放

本文只定义商业广告与低价值订阅邮件的离线标注，不承担病毒、钓鱼、恶意附件或 SMTP 垃圾邮件网关判断。

## 标签

| 标签 | 定义 | 典型例子 |
|------|------|----------|
| `ad` | 主要目的为促销、导购、营销活动或用户当前不需要的批量订阅内容 | 折扣、优惠券、促销简报、批量产品推荐 |
| `transactional` | 由用户行为、订单、账户或服务状态触发，主要目的是完成或告知一项事务 | 验证码、账单、航班变更、订单状态、安全通知 |
| `other` | 正常沟通或系统消息，但不属于上面两类 | 人工往来、工单回复、项目通知 |
| `uncertain` | 仅凭当前脱敏内容不能可靠判断 | 同时包含订单状态和大篇幅促销、关键上下文被移除 |

`uncertain` 不进入训练集或阈值验收集。解析失败本身不是 `ad` 证据；能够从其他字段判断时仍按内容标注，信息不足时标为 `uncertain`。

## 标注规则

1. 以邮件主要目的为准，不以单个关键词、退订头、链接数量或跟踪像素直接定类。
2. 事务邮件附带交叉销售时，只要核心信息仍是用户触发的事务，标为 `transactional`；以促销为主体、事务信息只是引流入口时标为 `ad`。
3. 合法订阅不等于非广告；是否经过用户订阅只影响运营处理，不改变内容类别。
4. 发件域名、品牌知名度和历史印象不能替代当前邮件证据。
5. 标注记录只保存脱敏摘要、命中的证据族和必要元数据，不保存密码、Token、完整 HTML 或真实用户正文。
6. `confirm_ad` 产生 `ad` 正样本；人工放行且明确选择误判产生非广告负样本；没有选择原因的普通放行写 `uncertain`。

## 数据切分与复核

- 按时间和发件域同时隔离训练、校准、验证集合，避免同一群发活动跨集合泄漏。
- 阈值附近、人工规则覆盖和解析警告样本必须进入双人复核。
- 标注分歧保留两份原始判断和最终裁决，不覆盖历史记录。
- 每批样本记录准则版本、脱敏方法、抽样范围和复核人；不得在仓库提交生产原始 EML。

## S0 合成样本

`docs/filter-contract/v1/eml` 使用 `.example` 保留域和合成正文，覆盖 `ad / transactional / other / uncertain` 以及解析失败、重复 Header、多 URL、内嵌图片和 4 KiB 附件边界。它们用于契约和解析回归，不用于选择生产权重或阈值。
