# 管理后台国际化设计

## 1. 背景与范围

MailHub 登录后的 React 管理后台当前使用硬编码中文。首期增加简体中文、英语和日语，登录页暂不纳入；后续可在相同资源结构中继续添加语言，并将国际化扩展到登录页。

首期覆盖：

- 顶部栏、侧边导航和主题设置
- 仪表盘、服务器、邮箱、邮件、过滤规则、系统配置、外部访问和全局搜索页面
- 抽屉、对话框、表单提示、空状态、Toast 和前端生成的错误提示
- 前端格式化的日期和数字

首期不翻译：

- 邮件主题、正文、地址及附件内容
- 用户填写的名称、备注、域名和规则内容
- 后端直接返回且没有稳定错误码的消息
- 登录页

## 2. 技术方案

- 使用 `i18next` 和 `react-i18next`，由 React Context 驱动界面更新。
- 使用稳定的语义化翻译键；资源按 `common`、`layout`、`pages` 命名空间拆分。
- 支持 `zh-CN`、`en-US`、`ja-JP`，缺失翻译回退到 `zh-CN`。
- 默认使用简体中文，用户主动选择后写入 `mailhub.language`。
- 切换语言时同步更新 `<html lang>`，日期通过当前语言的 `Intl.DateTimeFormat` 格式化。
- 动态数量和名称通过 i18next 插值生成，业务数据保持原样。

## 3. 交互设计

- 桌面端在全局搜索框左侧放置带地球图标的语言下拉框。
- 语言名称使用其本地写法：`简体中文`、`English`、`日本語`。
- 窄屏隐藏全局搜索框时保留紧凑语言选择，确保移动端仍可切换。
- 选择后立即更新整个管理后台，不刷新页面，不改变当前路由或表单状态。

## 4. 兼容与验证

- 不改变 API、路由和后端模板协议。
- 生产构建必须通过。
- 检查三种语言资源键完全一致、非法持久化值回退到简体中文、切换后 HTML `lang` 与本地存储同步。
- 检查桌面与移动宽度下语言控件不遮挡标题、搜索和操作按钮。
